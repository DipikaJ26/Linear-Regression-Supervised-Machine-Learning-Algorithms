# Linear Regresson-Supervised-Machine-Learning-Algorithms

Linear Regression is a supervised learning algorithm used to predict a coninuous value. It models the relationship between input i.e. features and output i.e. target variable by fitting a straight line.

The stright line will be in the form : 

y= m1.x1+m2.x2+m3.x3+...+mn.xn +c

where , x1,x2,x3,...,xn  : Features

m1,m2,m3,...,mn : slopes

c : y-intercept

In this project, the dataset is of Student Performance Analysis and the columns are Hours Studied, Previous Scores, Sleep Hours, Sample Question Papers Practiced,	Extracurricular Activities and Performance Index.
In this the target variable is Performance Index. That means using all the features the ML model is build using Linear Regression algorithm to predict the student's Performance Index.
